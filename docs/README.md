The Bursar documentation is a [Docusaurus](https://docusaurus.io/) site built
from this directory and published to
[https://zonastery.github.io/bursar/](https://zonastery.github.io/bursar/).

## Requirements

- Node.js 20+ and npm
- Python 3.12+ (API reference and notebook generation)
- Bun (JavaScript API reference via TypeDoc)

## Local development

```bash
npm install
```

The `prestart` and `prebuild` steps regenerate the generated content
(Python/TypeScript API reference, notebooks, and ERD) automatically.

```bash
npm start          # dev server with live reload
npm run build      # static output into build/
npm run serve      # preview the built site locally
```

## Content

- `docs/docs/**` — hand-written pages: getting started, concepts, guides, CLI,
  and API intros.
- `docs/python-api/reference/**` and `docs/javascript-api/reference/**` —
  generated by Sphinx and TypeDoc on every build.
- `docs/docs/notebooks/**` — generated from the Python notebooks.

Hand-written pages use the shared formatting conventions (Diátaxis structure,
Tabs for Python/TypeScript, Mermaid diagrams, SEO descriptions) — follow the
existing pages when adding new ones.

## LLM-friendly files (`llms.txt` / `llms-full.txt`)

The site publishes [llms.txt](https://llmstxt.org/) files at
`/bursar/llms.txt` (curated link index) and `/bursar/llms-full.txt`
(concatenated full text of every page linked from the index's main sections).

Both are generated by `scripts/gen-llms-files.py` from a curated manifest and
committed to `static/`; they are regenerated automatically on every
`prebuild`/`prestart` (via `npm run generate:llms` standalone). When adding or
removing doc pages, update the manifest in the script so the index and full
text stay in sync.

## Deployment

Pushing to `main` (or dispatching manually) triggers the `Deploy Docs`
workflow (`.github/workflows/docs.yml`), which builds the site and publishes
it to GitHub Pages. There is no manual `docusaurus deploy` step.
