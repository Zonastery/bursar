# Python stores

```python
from bursar.stores.memory import MemoryStore
from bursar.stores.postgres import PostgresStore, run_migrations
from bursar.stores.supabase import HttpxSupabaseStore
```

`CreditStore` in `bursar.stores.base` is the custom-store abstraction.
Implementations provide the canonical account, ledger, lot, lease, plan, team,
configuration, and billing-support operations required by their capabilities.

Installation remains separate:

```python
run_migrations(database_url)
store = PostgresStore(database_url)
```
