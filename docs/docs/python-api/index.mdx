# Python API

Python 3.12 and 3.13 are supported.

```python
from bursar import Bursar, LedgerCursor, LedgerEntry, LedgerPage
from bursar.stores.postgres import PostgresStore

bursar = Bursar.create(credit_store=PostgresStore(database_url))
```

Use `bursar.credits` for account, lease, plan, team, and ledger operations;
`bursar.catalog` for canonical configuration; and optional `bursar.billing`
for provider lifecycle operations.
