# JavaScript API

The package is ESM-only and requires Node.js 22 or newer.

```ts
import {
  Bursar,
  PostgresStore,
  type LedgerCursor,
  type LedgerEntry,
  type LedgerPage,
} from "@zonastery/bursar";

const bursar = new Bursar({ creditStore: new PostgresStore(databaseUrl) });
```

The facade exposes `credits`, `catalog`, and optional `billing` capabilities.
