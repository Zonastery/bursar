# JavaScript stores

```ts
import { CreditStore, PostgresStore } from "@zonastery/bursar";
```

`PostgresStore` uses the canonical SQL functions. Extend `CreditStore` for a
custom backend and preserve account locking, idempotency, append-only history,
lot allocation, and stable `(createdAt, entryId)` cursor ordering.

The JavaScript package never installs SQL. Run the migration CLI during
deployment before constructing the store.
