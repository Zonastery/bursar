# Bursar

Bursar is a reusable credit-ledger and billing SDK for Python and JavaScript.
Applications construct one `Bursar` facade and use its `credits`, `catalog`,
and optional `billing` capabilities.

## Install the database

```bash
export DATABASE_URL=postgresql://...
bursar migrate
```

The checksum runner is the only installation path. Stores and facades never
create database objects.

## Create a facade

```python
from bursar import Bursar
from bursar.stores.postgres import PostgresStore

bursar = Bursar.create(credit_store=PostgresStore(database_url))
```

```ts
import { Bursar, PostgresStore } from "@zonastery/bursar";

const bursar = new Bursar({
  creditStore: new PostgresStore(process.env.DATABASE_URL!),
});
```

All monetary mutations append a `LedgerEntry`, update the locked canonical
account balance, and allocate or reverse lots atomically. History uses stable
cursor pagination through `LedgerCursor` and `LedgerPage`.

Configuration has exactly four public sections: `usage`, `credits`, `plans`,
and `payments`.
