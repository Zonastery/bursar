# Bursar

Bursar is a reusable credit-ledger and billing SDK for Python and JavaScript.
Applications construct one `Bursar` facade and use its `credits`, `catalog`,
and optional `billing` capabilities.

## Install the database

```bash
export DATABASE_URL=postgresql://...
bursar migrate
```

The checksum runner is the only installation path. Stores and facades never
create database objects.

## Create a facade

`PostgresStore` is imported from the package top level and is bound to one
tenant, so provision a tenant first (see [multi-tenancy](./multitenancy.mdx)).

```python
from bursar import Bursar, PostgresStore

store = PostgresStore(database_url, tenant_id=tenant_id)
bursar = Bursar.create(credit_store=store)
```

```ts
import { Bursar, PostgresStore } from "@zonastery/bursar";

const store = new PostgresStore(process.env.DATABASE_URL!, tenantId);
const bursar = new Bursar({ creditStore: store });
```

All monetary mutations append a `LedgerEntry`, update the locked canonical
account balance, and allocate or reverse lots atomically. History uses stable
cursor pagination through `LedgerCursor` and `LedgerPage`.

Configuration is one strict versioned document with `pricing`, `credits`,
`entitlements`, `admission`, `plans`, `commerce`, and `catalog` sections. See
the [canonical configuration](./configuration.mdx) reference for the validated
shape.
