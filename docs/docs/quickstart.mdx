# Quickstart

import Tabs from '@theme/Tabs';
import TabItem from '@theme/TabItem';

Ten minutes to a working credit ledger. You build *prompta*, an AI assistant,
and wire Bursar to meter completions, hold balances, and charge users.

## Prerequisites

- Python 3.12+ with `pip install bursar[postgres]`, or Node.js 22+ with
  `npm install @zonastery/bursar`
- PostgreSQL 16 reachable from `DATABASE_URL`

## 1. Install the schema

```bash title="Terminal"
export DATABASE_URL=postgresql://...
bursar migrate
```

:::note

`bursar migrate` applies the ordered SQL baseline, records checksums for every
file, and fails if an applied file changed. It is safe to re-run — a second run
is a no-op.

:::

Create a tenant (the printed UUID is your tenant id):

```bash title="Terminal"
bursar tenant create acme
# 018f7f5f-7b4a-7000-8000-000000000001
export BURSAR_TENANT_ID=018f7f5f-7b4a-7000-8000-000000000001
```

## 2. Publish a config

One strict, versioned document drives pricing, buckets, and plans. Save it as
`pricing.yaml`:

```yaml title="pricing.yaml"
version: 1
catalog:
  default_plan: free
pricing:
  operations:
    completion:
      measures:
        input_tokens: { unit: token }
        output_tokens: { unit: token }
      dimensions:
        model: { type: string }
  rate_cards:
    standard:
      operations:
        completion:
          rules:
            - when:
                model:
                  op: in
                  values: [gpt-4o, gpt-4o-mini]
              charge:
                type: per_unit
                measure: input_tokens
                rate: "0.0025"
                unit_size: "1000000"
          unmatched:
            action: reject
credits:
  buckets:
    promotional: { priority: 1 }
    purchased: { priority: 10 }
  default_bucket: purchased
plans:
  free:
    display_name: Free
    rate_card: standard
    allowed_operations: [completion]
    credit_allowance:
      amount: "10000"
      priority: 5
      window: { type: calendar, unit: month, count: 1 }
```

:::info Strict schema

The schema is strict: unknown fields are rejected, and all exact decimal
values are strings.

:::

Validate, then publish:

```bash title="Terminal"
bursar config validate pricing.yaml
bursar config set pricing.yaml
```

`config set` validates again, creates an immutable version, and activates it.
Check with `bursar config list`.

## 3. First credits

Connect the store to your tenant and build the facade:

<Tabs groupId="lang">
  <TabItem value="python" label="Python">

  ```python
  from bursar import Bursar, PostgresStore

  store = PostgresStore(database_url, tenant_id=tenant_id)
  bursar = Bursar.create(credit_store=store)
  ```

  </TabItem>
  <TabItem value="ts" label="TypeScript">

  ```ts
  import { Bursar, PostgresStore } from "@zonastery/bursar";

  const store = new PostgresStore(process.env.DATABASE_URL!, tenantId);
  const bursar = new Bursar({ creditStore: store });
  ```

  </TabItem>
</Tabs>

Register Ada and give her an account, a plan, and some credits. The free plan
carries a 10,000-credit monthly allowance:

<Tabs groupId="lang">
  <TabItem value="python" label="Python">

  ```python
  ada = "11111111-1111-4111-8111-111111111111"

  bursar.accounts.on_account_created(ada, event_key="signup")
  bursar.credits.add_credits(ada, 1000, entry_type="purchase")

  balance = bursar.credits.get_balance(ada)
  print(balance.balance, balance.lifetime_purchased)
  ```

  </TabItem>
  <TabItem value="ts" label="TypeScript">

  ```ts
  const ada = "11111111-1111-4111-8111-111111111111";

  await bursar.accounts.onAccountCreated({ accountId: ada, eventKey: "signup" });
  await bursar.credits.addCredits(ada, 1000, { type: "purchase" });

  const balance = await bursar.credits.getBalance(ada);
  console.log(balance.balance, balance.lifetimePurchased);
  ```

  </TabItem>
</Tabs>

`on_account_created` assigns the default plan and runs eligible signup grants;
`add_credits` with `entry_type="purchase"` grants into the default bucket and
appends a `purchase` ledger entry.

## 4. Charge for usage

Meter one completion as a `UsageMetrics` and deduct in a single atomic call.
This is 800 input tokens on gpt-4o, which the `standard` rate card prices at
`0.0025` credits per million tokens: `800 / 1,000,000 × 0.0025 = 0.000002`.

<Tabs groupId="lang">
  <TabItem value="python" label="Python">

  ```python
  from decimal import Decimal
  from bursar.metrics import UsageMetrics

  metrics = UsageMetrics(
      operation="completion",
      measures={"input_tokens": Decimal(800)},
      dimensions={"model": "gpt-4o"},
  )
  result = bursar.credits.deduct(ada, metrics, idempotency_key="turn_12345")
  print(result.amount, result.allowance_consumed, result.balance_after)
  ```

  </TabItem>
  <TabItem value="ts" label="TypeScript">

  ```ts
  const result = await bursar.credits.deduct(
    ada,
    {
      operation: "completion",
      measures: { input_tokens: 800 },
      dimensions: { model: "gpt-4o" },
    },
    "turn_12345",
  );
  console.log(result.amount, result.allowanceConsumed, result.balanceAfter);
  ```

  </TabItem>
</Tabs>

The `DeductionResult` reports the split between allowance and balance:

| Field | Meaning |
| --- | --- |
| `amount` | Net charge debited from the balance (after allowance) |
| `allowance_consumed` | Amount covered by the plan's free allowance |
| `balance_after` | Exact balance after the charge |

On the free plan the 0.000002-credit charge is covered by the monthly
allowance, so `amount` is 0, `allowance_consumed` is 0.000002, and
`balance_after` is 1000.000000. Replaying `deduct` with the same
`idempotency_key` is a no-op. Unmetered models are rejected by the
`unmatched: reject` policy.

Every mutation is visible in the append-only ledger. Each ledger entry
exposes its entry id, type, exact amount, and creation time:

<Tabs groupId="lang">
  <TabItem value="python" label="Python">

  ```python
  for entry in bursar.credits.list_ledger_entries(ada, limit=50).items:
      print(entry.entry_id, entry.entry_type, entry.amount, entry.created_at)
  ```

  </TabItem>
  <TabItem value="ts" label="TypeScript">

  ```ts
  const page = await bursar.credits.listLedgerEntries(ada, { limit: 50 });
  for (const entry of page.items) {
    console.log(entry.entryId, entry.entryType, entry.amount, entry.createdAt);
  }
  ```

  </TabItem>
</Tabs>
