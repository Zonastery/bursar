# Canonical configuration

The public `BursarConfig` contains only `usage`, `credits`, `plans`, and
`payments`. Unknown keys are rejected, including removed historical shapes.

```yaml
usage:
  models:
    _default: input_tokens + output_tokens
credits:
  buckets:
    purchased:
      priority: 10
plans:
  free:
    label: Free
    included_credits: 1000
payments:
  subscriptions: {}
  topups: {}
```

Publish a draft, then activate it atomically:

```python
version = bursar.catalog.publish_draft(config, label="2026-07")
bursar.catalog.activate(version)
```

```ts
const version = await bursar.catalog.publishDraft(config, "2026-07");
await bursar.catalog.activate(Number(version));
```

Activation synchronizes the catalog and marks the selected document active in
one database operation. Pricing, billing offers, and auto-recharge policy all
read that active document.
