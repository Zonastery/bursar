# Storage backends

Python stores are under `bursar.stores`:

```python
from bursar.stores.memory import MemoryStore
from bursar.stores.postgres import PostgresStore
from bursar.stores.supabase import HttpxSupabaseStore
```

JavaScript exports `CreditStore` and `PostgresStore` from
`@zonastery/bursar`.

Use the memory store for deterministic unit tests and PostgreSQL for durable,
concurrent account state. The Supabase HTTP store calls the same canonical
RPCs and observes the same account/ledger contract.

Custom stores implement `CreditStore`. They must preserve idempotency, account
locking semantics, append-only ledger history, cursor ordering by
`(created_at, entry_id)`, and atomic lot allocation.

No store performs installation. Run `bursar migrate` with `DATABASE_URL`
before constructing a store.
